# レイアウト案の静止画モック

React 版デシャップ画面のレイアウト案を、見た目だけ先に HTML で描いたもの。実装（`src/views/`）の見た目の正にする。
ブラウザで直接開ける（データは架空の固定値。操作はできない）。

| ファイル | 案 | 実装 |
| --- | --- | --- |
| `a-rail.html` | A. 伝票レール（伝票が古いほど垂れ下がる） | `src/views/rail/` |
| `b-stove.html` | B. コンロ盤（画面がコンロ10口そのもの） | `src/views/stove/` |
| `c-board.html` | C. 一枚の板（囲みなし、1卓1行） | `src/views/board/` |

案0（カード型、`src/views/cards/`）はモック無しで実装した。

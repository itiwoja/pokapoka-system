# ホール表示案 A/B/C を無効化した経緯と、戻し方

> 出典：オーナー判断（2026-09-03）。「ホールは A/B/C に分ける前の状態がいい。構造は残して使わない形に」
> 関連：[2026-07-16 議事録 §4](2026-07-16_議事録_使用感デモ・UI方針.md)（ホールUIは引き算方針で複数案試作） / Issue #155 phase1

**一言サマリ**：ホールの表示案切替 **A/B/C を既定で無効**にし、ホールモードを **a818051 マージ前と同じ「グリッドを出したまま操作だけ止めた読取専用」** に戻した。**コードは削除していない**ので、フラグ 1 行を `true` にすれば A/B/C はそのまま復活する。

---

## 1. 戻し方（これだけ）

`kds-a-grid.html` の JS 冒頭付近にあるフラグを `true` にする。

```js
var HALL_PROTO_ENABLED = false;   // ← true にすると A/B/C が戻る
```

これで以下がすべて元に戻る。ほかに触る場所はない。

- ヘッダーの `A` `B` `C` スイッチが再表示される
- ホールモードでグリッドと予約ストックが試作ビューに差し替わる
- 選択中の案（LocalStorage / URL ハッシュ）に従って A / B / C のレイアウトが出る

## 2. 何が残っていて、何が変わったか

**残してあるもの（削除ゼロ）**

| 種別 | 内容 |
| :--- | :--- |
| HTML | `#hallProtoSwitch`（A/B/Cボタン3個）、`#hallProtoView` と `.hall-view-a/-b/-c` の全マークアップ |
| CSS | `.hall-proto-btn` / `.hall-view-*` / `.hall-panel` 等のスタイル一式 |
| JS | `hallLayout` / `applyHallLayout()` / `setHallLayout()` / `renderHallViews()` とボタンのイベント |
| 永続値 | LocalStorage `kds_hall_proto_v1`、URL ハッシュ `#hall=B` の解釈 |

**変えたもの（4箇所）**

1. `body.hall-proto-on` が付いているときだけ A/B/C スイッチを表示
2. 同じく、試作ビューの表示と「グリッド・予約ストックを隠す」指定を有効化
3. `applyHallLayout()` で `hall-proto-on` を `HALL_PROTO_ENABLED` に応じて付け外し
4. 無効時は `renderHallViews()` を早期 return（非表示DOMの組み直しを止める。常時稼働端末の無駄を避けるため）

`hall-proto-b` のような**案のクラスは無効時も付いたまま**にしてある。フラグを戻した瞬間に、以前選んでいた案がそのまま復元されるようにするため。

## 3. 無効時のホール（＝マージ前の挙動）

- グリッドと予約ストックを**表示したまま**、品目・コンロの操作を無効化（`pointer-events: none` / `opacity: .82`）
- 伝票ボタン「伝」と削除ボタンを非表示
- 予約ストックの「卓番」「調理開始」「＋」「×」だけは操作可のまま
- 読取専用の注記を表示

## 4. 経緯（なぜこうなっていたか）

| | |
| :--- | :--- |
| 作成 | `a818051` `feat: ホール表示案と予約・提供状態を追加`（2026-08-27・村上壱基さん） |
| main 到達 | 2026-09-01、`6fae6f9` **PR #211**（`fix/205-relay-kds-retry`）経由 |

PR #211 はタイトル上「relay-kds のリトライ修正」であり、**ホール表示案 A/B/C はその PR の主題ではなく、ブランチ統合に相乗りする形で main へ入った**。レビューを経ていない可能性がある。

`git log -S"hall-proto-btn" --all` で該当は `a818051` の 1 コミットのみ。以後変更されていない。

## 5. 注意

- **A/B/C の比較検討自体をやめたわけではない**。Issue #155 phase1 の試作として再開しうるため、コードを残している
- 既に B や C を選んだ端末は LocalStorage に残っているが、無効時は表示に影響しない
